# 省实游泳队 · GitHub Pages 版

这是一个无需服务器的单机版队伍管理应用，包含学生档案、比赛成绩、训练惩罚、数据备份与离线缓存。

## 数据说明

- GitHub 只托管静态页面，不接收或保存学生数据。
- 录入的数据保存在当前设备的浏览器 `localStorage` 中。
- 每台手机的数据相互独立，不会自动同步。
- 清除浏览器网站数据、删除主屏幕应用或更换站点域名可能导致数据丢失。
- 请定期在“设置 → 数据与设置”中导出 JSON 备份。

## GitHub Pages 部署

1. 创建 GitHub 仓库，例如 `shengshi-swim-team`。
2. 将本目录全部文件上传到仓库默认分支的根目录。
3. 打开仓库 `Settings → Pages`。
4. 在 `Build and deployment` 中选择 `Deploy from a branch`。
5. Branch 选择 `main`，目录选择 `/ (root)`，保存。
6. 等待 GitHub Actions 发布完成。

默认网址格式：

```text
https://GitHub用户名.github.io/shengshi-swim-team/
```

## iPhone 安装

1. 使用 Safari 打开 Pages 地址。
2. 点击底部“分享”按钮。
3. 选择“添加到主屏幕”。
4. 首次打开后可在飞行模式下验证离线使用。

## 当前功能

- 学生档案、分组、在队状态和教练头像
- 游泳成绩、个人最好成绩、分段与技术数据
- 任意正整数单趟惩罚距离与累计完成量
- 数据导出、文件分享、导入与空白重置
- 备份提醒、存储额度和本机存储状态
- PWA 安装入口、离线状态提示和应用更新提示
